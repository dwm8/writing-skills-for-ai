# Writing Skills for AI

A home for the writing skill I currently use, updated as future evaluations produce a new winner.

The current selection is [Prose, version 2.2](skills/prose/SKILL.md). It contains rules for clear, natural writing: grounding claims, choosing precise language, keeping references clear, and varying sentence rhythm.

## Use the skill

Read [the skill instructions](skills/prose/SKILL.md) and apply them when asking an AI to write or edit. For agents that load skills from folders, copy the `skills/prose` folder into the agent's skills directory. The included `agents/openai.yaml` supplies display metadata for Codex.

## Future winners

When a new skill wins, add or update its folder under `skills/` and update the current selection linked above. Include its version and a short explanation of the choice in the commit. Git history preserves earlier selections.

This repository starts with an exact copy of the installed Prose 2.2 skill. It does not yet include evaluation results or a ranking of alternatives.
